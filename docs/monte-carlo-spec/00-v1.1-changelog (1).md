# Monte Carlo Specification — changelog v1.1

## Decisioni chiuse

1. **Esecuzione:** frontend tramite Web Workers; backend responsabile dello snapshot DB/API.
2. **Intensità persistente:** AR(1) mean-reverting verso `mean_intensity` scenario-specifica con `rho = 0.85`.
3. **Limite variazione intensità:** incorporato nella Gaussiana troncata condizionata, non tramite clamp.
4. **Ingresso nuovo scenario:** P95 soft threshold = 0.40 nel primo mese e 0.70 nel secondo.
5. **Solver entry:** bisezione deterministica, tolerance `1e-10`, max 100 iterazioni.
6. **Primo mese assoluto della simulazione:** usa la distribuzione base dello scenario iniziale, non la regola entry.
7. **Nearest correlation:** Higham + Dykstra, tolerance `1e-10`, max 100 iterazioni.
8. **Delta massimo correlazione:** `0.02` confermato perché già presente nel capitolo 14 v1.0.
9. **Boundary dati:** il motore riceve sempre decimali; eventuale conversione DB avviene una sola volta nello Snapshot API.
10. **Main thread Angular:** non esegue il loop Monte Carlo.
